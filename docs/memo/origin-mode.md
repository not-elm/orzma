# Origin Mode

ここでは[vt510](../references/vt510.pdf) からOrigin Modeにフォーカスした機能をメモする。

## モード

このモードはカーソルのアンカーを決定するために使用される。モードは以下の２つが存在する。
- WithinMargins
- UpperLeftCorner
  
### WithinMargins

上下左右それぞれにマージンを割り当てる。（単位はセル）  
カーソルはマージン領域外に移動できない。

左右方向は以下の仕様が存在する。
- DECSLRMはDECLRMMが設定されている場合だけ有効
- DECLRMMをリセットすると、左右マージンはページ左右端へ戻る

### UpperLeftCorner

スクリーン左上を起点とする。マージン領域外にカーソルが移動できる。

## 制御関数一覧

VT510のPDF 77〜78ページにあるMargins and Scrollingの一覧をもとに、Origin Modeおよびマージンに関連する制御関数をまとめる。

| 制御関数 | 7-bit形式 | 7-bitバイト列 | 説明 |
| - | - | - | - |
| DECBI | `ESC 6` | `1B 36` | カーソルを1列左へ移動する。左マージン上では、マージン内のデータを右へ1列移動する。 |
| DECFI | `ESC 9` | `1B 39` | カーソルを1列右へ移動する。右マージン上では、マージン内のデータを左へ1列移動する。 |
| IND | `ESC D` | `1B 44` | カーソルを同じ列のまま1行下へ移動する。下マージン上では、マージン内を上へスクロールする。 |
| DECOM set | `CSI ? 6 h` | `1B 5B 3F 36 68` | カーソル座標の原点と移動可能範囲をマージン内に設定する。 |
| DECOM reset | `CSI ? 6 l` | `1B 5B 3F 36 6C` | カーソル座標の原点をスクリーン左上に設定し、マージン外への移動を許可する。 |
| RI | `ESC M` | `1B 4D` | カーソルを同じ列のまま1行上へ移動する。上マージン上では、マージン内を下へスクロールする。 |
| DECSCLM set | `CSI ? 4 h` | `1B 5B 3F 34 68` | スクロール方式をsmoothに設定する。 |
| DECSCLM reset | `CSI ? 4 l` | `1B 5B 3F 34 6C` | スクロール方式をjumpに設定する。 |
| DECLRMM set | `CSI ? 69 h` | `1B 5B 3F 36 39 68` | DECSLRMによる左右マージンの設定を有効にする。 |
| DECLRMM reset | `CSI ? 69 l` | `1B 5B 3F 36 39 6C` | DECSLRMを無効にし、左右マージンをページ左右端へ戻す。 |
| DECSLRM | `CSI Pl ; Pr s` | `1B 5B {Pl} 3B {Pr} 73` | 左右マージンを設定する。DECLRMMがsetの場合のみ有効。 |
| DECSSCLS | `CSI Ps SP p` | `1B 5B {Ps} 20 70` | スクロール速度を設定する。 |
| DECSTBM | `CSI Pt ; Pb r` | `1B 5B {Pt} 3B {Pb} 72` | 上下マージンを設定する。 |

`Pt`、`Pb`、`Pl`、`Pr`は1始まりで、指定された両端をマージン領域に含む。

| パラメータ | 説明 | 省略時の値 |
| - | - | - |
| `Pt` | 上マージンの行番号 | 1 |
| `Pb` | 下マージンの行番号 | スクリーンの行数 |
| `Pl` | 左マージンの列番号 | 1 |
| `Pr` | 右マージンの列番号 | ページ幅（80列または132列） |

DECSTBMでは`Pt < Pb`、DECSLRMでは`Pl < Pr`でなければならない。DECSLRMのスクロール領域は最低2列である。DECSTBMまたはDECSLRMを実行すると、カーソルはホーム位置へ移動する。VT510はこれを「ページの1行1列」と書いているが、DECOMがsetの状態でページ1行目へ動かすとp.195の「カーソルはマージン領域外に移動できない」に反するため、orzmaではDECOMが定めるホーム（set時は上マージン、reset時は画面左上）へ移動する。

DECSSCLSの`Ps`は次のスクロール速度を指定する。

| `Ps` | スクロール方式 | 速度 |
| - | - | - |
| 省略、`0`〜`3` | Smooth 2 | 9行/秒 |
| `4`〜`8` | Smooth 4 | 18行/秒 |
| `9` | Jump | 受信速度に追従 |
